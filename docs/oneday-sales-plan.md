# 원데이 방문 구분·매출 연결

## 최종 동작

- 출석보드에서 원데이는 이름만 입력해 추가한다. 이름을 누르면 방문 정보에서 일반 / 오붓을 선택한다.
- 출석 아이콘은 출석·불참 처리만 담당한다. 이름 옆에는 방문 구분 배지를 표시하지 않는다.
- 일반은 원데이만 / 월회원 등록을 선택한다.
- 원데이만은 출석 확인 시 30,000원 매출을 자동 등록한다. 예약만 추가하면 매출은 아직 생기지 않는다.
- 기존 30,000원 원데이 매출을 선택해 연결하면 새 매출을 만들지 않는다. 후보는 날짜·이름·금액·결제수단·ID를 확인하여 직접 선택한다.
- 월회원 등록은 원데이 매출을 새로 생성하지 않는다. 기존에 연결된 원데이 매출은 `월회비 포함`으로 보존하고 합계에서 제외한다. 월회원권 매출은 3만원을 포함한 총액이어야 한다.
- 기존 월회원권 매출도 연결할 수 있다. 회원 등록 전에는 연결을 비워 둘 수 있으며 출석 화면에 연결 필요 안내가 표시된다.
- 일반 원데이를 신규 회원으로 연결할 때 회원·월회원 매출 저장 성공 후 출석 연결과 포함 처리를 수행한다. 실패하면 팝업을 유지하고 재시도한다.
- 오붓은 출석보드에서 표시만 한다. 개인별 매출·정산대기를 생성하지 않으며 월말 입금은 기존 수기 입력을 사용한다.
- 과거 원데이는 미분류로 유지한다. 이름 → `방문 정보`에서 구분과 기존 매출을 지정한다. 이름만으로 자동 연결하지 않는다.

## 보존·취소

- 출석과 자동 매출은 DB 트리거로 같은 트랜잭션에서 저장한다. 자동 매출 ID는 예약 ID의 음수이며, 기존 음수 ID 충돌은 덮어쓰지 않고 오류로 처리한다.
- 자동 매출이 있는 출석을 되돌리거나 취소하면 해당 매출을 합계에서 제외한다. 재출석 시 같은 매출을 다시 활성화한다.
- 기존 수기 매출은 출석 취소만으로 제외하지 않는다. 월회비 포함을 명시한 경우에만 합계에서 제외한다.
- 연결된 원데이는 취소 상태로 보존한다. 연결된 매출의 직접 수정·삭제와 다른 출석의 중복 연결은 DB에서도 차단한다.
- 한번 연결한 원데이 매출의 교체·해제 및 연결 후 일반→오붓 변경은 현재 막혀 있다. 정정이 필요한 경우 해당 기록을 확인한 뒤 별도 처리한다.
- 월회비 포함은 기록상 총액을 중복 집계하지 않는 처리이며 원데이 결제 환불을 실행하지 않는다.

## 적용

1. Supabase SQL Editor의 새 쿼리에 `supabase/migrations/20260930_oneday_sales.sql` 전체를 붙여 넣고 실행한다.
2. 결과의 `booking_trigger_ready`, `sale_guard_ready`가 모두 true인지 확인한다.
3. 변경된 앱 코드를 배포한 뒤 새로고침한다. SQL만 적용해도 기존 배포 화면은 바뀌지 않는다.

운영 DB SQL은 사용자가 직접 실행했으며 두 확인 결과가 true임을 보고했다. SQL 자체는 기존 행을 갱신하거나 삭제하지 않는다.

## 검증

- `node --test src/bookingSave.test.js src/onedaySales.test.js`
- 별도 설치한 PGlite 경로로 `PGLITE_MODULE=/path/to/pglite/dist/index.js node scripts/test-oneday-sql.mjs`
- `npm run build -- --outDir /tmp/yogapian-oneday-build`

운영 DB 데이터 생성 없이 로컬 PostgreSQL 엔진에서 기존 데이터 보존, 예약과 출석 구분, 중복 연결 차단, 월회비 포함, 오붓 미생성, 취소/재출석, 오류 롤백, SQL 재실행을 확인한다.

## 날짜 타입 오류 보정

운영 환경의 예약 날짜(date)와 매출 날짜(text)를 CASE에서 혼합해 출석 저장이 실패했다. `20260930_fix_oneday_date_type.sql`은 기존 함수의 날짜 대입을 매출 행의 실제 타입으로 변환하도록 수정한다. 이 수정 파일만 추가 실행하고 `date_fix_ready=true`를 확인한다. 로컬 검증은 sales.date의 text/date 두 타입을 모두 포함하며 이전 오류 재현 및 보정 후 동작을 검사한다.
